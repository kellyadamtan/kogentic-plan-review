# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults and personal or political attacks are not accepted, in issues, pull requests or anywhere else in the project.

## Reporting

If you see or experience unacceptable behaviour, contact the maintainer privately through GitHub ([@kellyadamtan](https://github.com/kellyadamtan)). Reports are handled confidentially. Maintainers may remove comments, commits or contributions that break this code, and may ban contributors who repeatedly do so, as described in the Contributor Covenant's enforcement guidelines.
